# AQUA 网关并发配置规则文档

## 一、用户分类与默认并发

| 用户类型 | 默认并发 | 条件 |
|---------|---------|------|
| 老用户 | 4 | 2026-07-21 23:00 CST 前注册 |
| 新用户 | 2 | 2026-07-21 23:00 CST 后注册 |

## 二、特殊用户覆盖（可编辑配置）

通过修改 `scheduler.py` 中的 `_SPECIAL_USER_OVERRIDES` 字典管理：

```python
_SPECIAL_USER_OVERRIDES = {
    "xiaoliang": (8, "永久提升"),    # 永久提升至8并发
    "logarh":    (8, "永久提升"),    # 永久提升至8并发
    "user111":   (8, "临时考察"),    # 考察期临时8并发
    "小涑a":    (0, "永久无限量"),   # 无限量并发（0 = 不限）
}
```

### 添加新用户
1. 在 `_SPECIAL_USER_OVERRIDES` 中添加新条目
2. 格式：`"用户名关键词": (并发数, "标签")`
3. 重启网关服务生效

### 修改并发数
1. 直接修改对应用户的元组中的数字
2. 例：`"user111": (12, "临时考察")` 表示改为12并发

### 标签说明
- `"永久提升"`：不限期的并发提升
- `"临时考察"`：考察期临时配置，后续根据使用情况调整

## 三、并发检测机制（v9.2 毫秒级精准）

### 检测流程
1. 每个请求到达时记录开始时间戳（毫秒精度）
2. 检查前先清理超过 120 秒无响应的陈旧请求
3. 比较当前活跃并发数与配置限制
4. 超限时返回 429 + 中文提示

### 超时自动释放
- 配置：`CONCURRENCY_REQUEST_TIMEOUT = 120.0` 秒
- 超过该时间的并发请求视为已释放，自动回收并发槽位
- 防止客户端断连导致的并发计数不准确

## 四、商业检测监控名单

以下用户的商业行为将受到特别监控：

| 用户 | 监控级别 | 标签 | 说明 |
|------|---------|------|------|
| MaiBot | 严格 | 特殊监控 | 应用软件，监测高危行为 |
| logarh | 严格 | 特殊监控 | 监测高危行为 |
| user111 | 严格 | 考察监控 | 考察期用户 |

当置信度 >= 70 时触发 `【商业检测-高危】` 日志。
当置信度 >= 70 且用户为监控名单成员时触发 `【特殊监控-高危】` 日志。

## 五、平台控制台显示

### 特殊用户会看到
- `concurrency_limit`: 实际配置的并发数
- `special_tag`: "临时考察" / "永久提升"
- `special_reason`: 配置原因说明

### 普通用户
- 不显示特殊标签
- 按用户类型显示默认并发数

## 六、修改流程

1. 编辑 `gateway/app/scheduler.py` 中的 `_SPECIAL_USER_OVERRIDES`
2. 重启网关服务（port 8000）
3. 验证：访问用户控制台查看并发数和标签是否更新
